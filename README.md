Hospital Analysis Dashboard
A comprehensive Power BI dashboard designed to analyze hospital operations, patient demographics, and financial performance. This project transforms raw medical data into actionable insights using a modern, accessible data model.

📊 Project Overview
This dashboard provides a high-level overview of hospital performance metrics, tracking 1,000 total patients across 4 major departments (Cardiology, General, Neurology, and Ortho) managed by a team of 8 doctors.

Key Performance Indicators (KPIs)

Total Patients: 1,000 



Average Treatment Cost: 38.10K 



Medical Staff: 8 Doctors 



Specialties: 4 Departments 

🛠️ Technical Features

Integrated Data Modeling: Built with a sophisticated back-end model that links patient records, department metrics, and doctor performance for seamless cross-filtering.



Modern Design Standards: Implements the latest CY24SU10 theme and AccessibleDefault settings to ensure high-contrast visibility and a professional 2024 aesthetic.


Temporal Analysis: Features a "Count of Patient ID by Month" line chart to track seasonal patient flow and admission trends.


📈 Visualizations Included

Department Performance: Comparison of treatment costs and discharge statuses across Neurology, General, Ortho, and Cardiology.


Demographic Insights: Analysis of "Length of Stay" and "Treatment Cost" segmented by Gender.



Staff Workload: A treemap visual identifying patient distribution across individual doctors (e.g., Dr. John, Dr. Mehta, Dr. Patel).



Operational Efficiency: Stacked bar charts showing the count of departments against the length of patient stay
